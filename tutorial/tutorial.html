Freedom CLI

WebView 桌面壳打包工具 · 任意语言后端 · 三平台

1. 新建项目

freedom init my-app
cd my-app
npm install

2. 调整标题栏（终端一键切换）

  • freedom titlebar native — 保留系统原生标题栏（默认）
  • freedom titlebar hidden — 隐藏标题栏视觉，仅保留 Windows 原生最小化 / 最大化 / 关闭按钮
  • freedom titlebar frameless — 完全无边框，按钮由前端自绘（模板已内置示例）

也可以直接编辑 freedom.config.js 里的 titlebar 字段。

3. 打包

freedom build
freedom build --platform all         # 三平台全量（win + mac + linux）
freedom build --platform win-x64     # 仅 Windows
freedom build --platform mac-arm64   # 仅 macOS Apple Silicon
freedom build --platform linux-x64   # 仅 Linux

前端经 Vite 打成单文件 HTML 后写入 dist/resources/，与随包分发的预编译壳二进制合并出可执行文件。不再依赖本机 Go 工具链，任一平台都能一键产出三平台产物。产物以 GUI 子系统运行，不会弹出 cmd 黑窗。

resources/ 内含壳运行时加载的前端页面 index.html 与配置 config.json；声明了 backend 时 backend/ 目录会被原样分发到 resources/backend/，壳启动后自动以 resources/ 为工作目录拉起后端进程（黑窗同样隐藏）。

3.5 调整产物目录（终端一键切换）

freedom config set outDir .     # 输出到项目根目录（dist 的上级）
freedom config set outDir dist  # 恢复默认 dist/

outDir 支持任意相对 / 绝对路径。输出到项目根目录时自动跳过 index.html 副本，不会覆盖项目源文件。

4. 配置项（freedom.config.js）

{
  name: 'my-app',        // 应用名 / 窗口标题 / exe 文件名
  width: 1024, height: 720,
  minWidth: 400, minHeight: 300,
  center: true,          // 启动居中
  debug: false,          // 开发者工具
  titlebar: 'native',    // native | hidden | frameless
  outDir: 'dist',        // 产物目录：dist（默认）| .（项目根目录）| 任意路径
  backend: undefined,    // 任意语言后端进程，如 { command: 'node', args: ['backend/main.mjs'] }
}
提示：freedom CLI 生成的每个文件都干净整洁，无任何冗余尾注，可直接作为交付产物使用。
