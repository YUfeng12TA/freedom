# R5 —— 缺陷审查收口 + 体积/提速 + 工具链扩展 + 三语言重写方向

冻结目标（逐字抄自用户 R5）：
「再补一次，并且继续审查freedom的新缺点优化，而且对体积的优化加快，并且增加内置一个扩展功能自动安装C++，RUST，GO等工具链并自动优化配置如果检测到配置好就不去检测，而且将freedom整个语言决定重写用RUST+C+++GO三重语言复杂允许调用子代理完成。」

拆解为五个可验收子目标：
- R5-A high 档 GUI 真机冒烟「再补一次」。验收：真实产物启动 → 临时明文目录出现 → 正常关窗后消失。
- R5-B 新缺点审查并修。验收：每条缺陷有 file:line 取证 + 回归测试（修复未附回归＝未完成）。
- R5-C 体积优化 + 构建提速。验收：体积构成有本轮实测数字，砍点有实测字节收益。
- R5-D 内置工具链自动安装扩展（C++/Rust/Go）+「检测到配置好就不去检测」。验收：探测缓存只存成功结论、失败不入缓存；install 默认打印、--apply 才执行；optimize 幂等且不破坏既有配置。
- R5-E 三语言重写方向。验收：多方案闸门（≥3 方向 + 对比表 + 推荐），冻结前不写一行业务码。
