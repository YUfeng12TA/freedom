# 决策（decisions）

更新于 2026-08-29T19:10:01+08:00 · 共 4 条

## DEC-1（2026-08-19）

- **决策**：v1.1.10 起 freedom build 不再调用 go build，改为分发随 npm 包携带/下载的预编译通用壳二进制，前端与配置写 exe 同目录 resources/
- **理由**：实现三平台打包零 Go 依赖、前后端语言自由（壳通过 resources/config.json 拉起任意语言后端子进程）
- **备选**：保留 go build 依赖（仍需本机 Go/CGO/WebView 框架，无法交叉编译 mac/linux）
- **supersededBy**：无

## DEC-2（2026-08-19）

- **决策**：build --platform all 时多平台产物分别输出到 outDir/<plat>/ 子目录，避免互相覆盖；缺壳时自动下载，下载失败抛清晰错误
- **理由**：单平台直出 outDir，多平台隔离目录；网络失败不再静默产生坏产物
- **备选**：缺壳即中止整个 build（过于严格，浪费已成功平台产物）
- **supersededBy**：无

## DEC-3（2026-08-20T09:26:45+08:00）

- **决策**：多平台分发用 Promise.all 无并发限制并行执行
- **理由**：平台数固定为 5，均为本地磁盘 IO，无共享可变状态，直接并行收益最大且零复杂度
- **备选**：p-limit 并发池（平台数少时过度设计）；串行 for（被替换，是提速瓶颈）
- **supersededBy**：无

## DEC-4（2026-08-20T09:26:45+08:00）

- **决策**：前端构建缓存以源码文件最大 mtime 为指纹，命中时跳过 npm run build 直接分发
- **理由**：秒级复用，典型全量 0.6s 降至 0.06s；mtime 比对零解析成本，改动任何源码/配置即自动失效
- **备选**：内容 hash（需读全部文件，慢）；vite 自带增量缓存（仍要走一次 vite 进程，收益小）
- **supersededBy**：无
